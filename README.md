# 🔢 React Counter App

A simple and interactive Counter App built with **React.js**. This project allows users to increase and decrease a counter value using interactive buttons.

## 🚀 Features

- ➕ Increase Counter
- ➖ Decrease Counter
- ⚡ Real-time UI Updates
- 🎯 React useState Hook

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3

## 📚 What I Learned

- Understanding React Components
- Using the `useState` Hook
- Managing State in React
- Handling Button Click Events
- Updating UI Dynamically

## 💻 Run Locally

```bash
npm install
npm run dev
```
